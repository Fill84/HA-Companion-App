Windows builds place the optional .NET 10 ha-hwmon.exe provider here.
This directory is bundled as hwmon/. Older .NET 8 output is not bundled.
The provider is inactive by default. No kernel driver or runtime is included.
Build using: node build-hwmon.js (from desktop-app, with the SDK in global.json).
See hwmon-helper/README.md in the source repository.
